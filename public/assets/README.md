# Profile assets

Replace these files with your own images:

- `profile-bg.jpg` — profile background photo. Recommended landscape/portrait source at least 1200px on the shorter side.
- `avatar.jpg` — round avatar photo. Recommended square image, at least 512×512.

Keep the exact filenames so no code changes are required. PNG/WebP can also be used if you update the extension in `src/App.tsx`.

Existing `profile-bg.svg` and `avatar.svg` are built-in fallbacks.


## Exact paths
```text
public/
└── assets/
    ├── profile-bg.jpg   # your background photo
    └── avatar.jpg       # your avatar
```

The names are case-sensitive on GitHub Pages.
